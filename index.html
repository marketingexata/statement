Integrasi Folder GitHub:

Saat halaman dibuka, dashboard otomatis memuat gambar template tiap bank dari link default di kode (TEMPLATE_DEFAULT_LINKS), atau dari folder GitHub bila link default kosong. Kalau gambar tidak ditemukan, otomatis dipakai template vektor bawaan. Isi kolom link di tiap bank di bawah untuk menggantinya tanpa mengubah kode, atau pakai Upload untuk gambar dari perangkatmu.

Kosongkan jika gambar berada di folder yang sama dengan file dashboard ini. Pengaturan ini tersimpan di browser ini; untuk membuatnya permanen, isi TEMPLATE_FOLDER_URL di dalam kode.
